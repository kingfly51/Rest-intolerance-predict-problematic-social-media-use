# Rest-intolerance-predict-problematic-social-media-use

This directory stores the complete set of code utilized across all sub-studies, including predominantly R scripts, supplemented by Python and Mplus code. Should you have any inquiries, please do not hesitate to reach out via email.


This repository contains all data, code, and documentation for reproducing the analyses in our study “ Rest Intolerance: An overlooked key factor influencing problematic social media use among Chinese adults.”

System Requirements
Hardware
Standard desktop computer (tested on systems with:)
CPU: Intel i5 or equivalent (minimum)
RAM: 8GB (16GB recommended for complex models)
Storage: 500MB available space


Software Dependencies
Core Requirements
R (version 4.4.1 or higher)
Python (version 3.12 or higher) - for machine learning analyses
Mplus (version 8.3) - for latent profile analysis

Tested Configurations
Windows 10/11 with R 4.4.1
macOS Monterey (12.6) with R 4.4.1
Ubuntu 20.04 LTS with R 4.4.1
